# ToDoApp


ToDoApp
    This is for anyone who would like a checklist while on their computer. The application is very easy to use and understand.
    Enter a task(s) you would like to complete while at your computer. Once created it will show you what time you created
    the task. Once you come to completing a task click the checkbox, it will move it to the completed section. Any task can be
    checked off at anytime, doesn't need to be done in order. In the completed section it will give the time you completed it.
    If you consider that your task isn't actually completed, unchecking the box will move it back to in-completed section, 
    keeping the original time you created the task.

    To run application

    What you need installed. Download Rust packages from www.rust-lang.org.
    Download Cargo if not already. 
    Download Visual Studio Build Tools 2022. 


    This is using a eframe application to popup a window to visual see what task need to be done. 

    To run application,
    cargo add eframe // this is only for the first time afterwards you will only use cargo run
    cargo run


    Now to create a desktop short cut.

    create build --release

    Locate target/release/todoapp.exe NOW go to file explorer and find that path. Right click on 
    todoapp.exe and create a shortcut. 

    Now usable whenever you please.
