# ToDoApp


ToDoApp is a interactive task management done in Rust and egui GUI frameworks. 
This was done just for me to learn Rust and different frameworks. 

How it works:

    User can enter multiples task in the text box. When the user has entered diff-
    erent task it will show the date and time of when it was created. A checkbox will
    be accessible to each task for when you want to mark it complete. When doing so it 
    will cross a line through the task and move it to completed seciton. Where it will 
    show the time it was completed. 

    There is also a big X red button that if you click it will get rid of the task.
    Not Complete it but actually delete it. 

    A all clear button that will erase all the task, just another option instead of 
    manually deleting each task.

    Implemented a calender that you can see what tasked you completed in the past.
    You cannot add task(s) in the future. This is only for user who want to keep track 
    of what they want to complete. Kinda like writing task on a piece of paper and 
    marking them off when you complete them. This is just a Digital version of that.


What you need to run this:

    1. Download Rust https://www.rust-lang.org/tools/install
    2. Download Cargo https://doc.rust-lang.org/cargo/getting-started/installation.html
    
    When you are finished downloading all of that go in the Directory and open a terminal 
    and type "cargo run"

    A small window will appear and there you go
